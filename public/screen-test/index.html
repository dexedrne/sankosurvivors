Sanko screen tests

These separate tests do not load the game or read its progress. Keep SankoSurvivors installed.

  1. Open each test in Safari and use Share → Add to Home Screen. Name them Sanko screen A and Sanko screen B.
  2. Open each test from its own Home Screen icon, then rotate to landscape.
  3. Compare whether the coloured grid reaches behind the right-hand clock/Wi-Fi area. Copy the screen details if needed.
Test A — current status-bar settingTest B — default status-bar setting

The two tests use the same drawing and fullscreen manifest. Only the legacy Apple status-bar setting differs. No wallet, sign-in or payment is involved.
